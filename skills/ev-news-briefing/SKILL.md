# 新能源行业早报 — 自动化工作流

## 核心流水线

```
Tavily多角度搜索 → 代码层时效过滤 → 域名信任加分 → AI生成 → 飞书推送
```

## 架构

| 层 | 职责 |
|---|---|
| config.json | 搜索关键词、AI模型、推送webhook、信任域名 |
| processor | Tavily搜索→质量评分→去重→AI生成→飞书发送 |
| Cron | 定时触发（替代容器while循环） |

## AI提示词核心要素

```
六板块：🚨风险→⚖️政策→🔗供应链→⚔️友商→🚀技术→📈资本
四要素：What/So What/Now What/Source
字数：280±20字/条
格式：索引/18 + 分隔线 + 风险等级标记 + 来源链接
```

## 时效性三层保障（关键）

| 层 | 方法 |
|---|---|
| L1代码 | 标题正则`20\d{2}年`，<当前年→丢弃 |
| L2 AI | 仅当月新闻，无法核实日期→跳过 |
| L3输出 | 每条必须`⏱ YYYY-MM-DD`，禁用"待核实" |

**关键教训**: Tavily不返回`published_date`，`days`参数不可靠。时效性必须代码+AI双层。

## 搜索策略

- 多角度关键词轮换（中英文），每板块3组
- `days=3`保证覆盖率，代码层过滤兜底
- 信任域加分不拦截（40+权威域名）

## 飞书推送

- `interactive`卡片markdown格式
- 消息间隔3s，限频11232→等5s重试
- 按板块分割消息

## 避坑

1. Tavily无日期→别依赖API参数，必须自己做时效检查
2. 域名白名单拦截→太激进会枯竭，改用加分策略
3. MoonShot/Kimi K2已停用→用DeepSeek-V3.2@硅基流动
4. RSS源大面积不可用→Tavily多角度搜索更可靠
5. while循环定时→Cron更稳定
