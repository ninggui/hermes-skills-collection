# 研究前置协议（Research-First Protocol）

**核心定位**：联网获取全量信息 → 提炼 → 补齐思路，先学后做。

## 触发条件

用户说出以下触发词 + 一个领域/方向：
- "你研究一下X"
- "你学习一下X"
- "你联网搜索一下X"
- "你查一查X"

**核心判断**：只要该领域**之前没搜索/研究过**（检查本地学习记录和知识库表），一律走完整研究流程。已研究过的领域直接复用上次成果，不重复研究。

## 执行流程（约40-60分钟，先学后做）

| 阶段 | 动作 | 产出 |
|------|------|------|
| 1. 行业通盘扫描 | 4-6 组关键词多角度搜索：行业现状/市场规模/头部玩家/趋势/经典案例/最新动态 | 行业地图 |
| 2. 知识点体系梳理 | 拆解"会做什么才叫懂行"：核心概念/技能树/常见坑/术语 | 知识点清单（必知/进阶/专家） |
| 3. 自主学习 | 对最高价值 2-4 个 URL 深度提取，交叉验证多源 | 学习笔记 |
| 4. 提炼方法论 | 转成可执行经验：最佳实践/避坑清单/可落地动作 | 方法论框架 |
| 5. 产出沉淀 | 写知识库文档 + 登记索引表 + 存本地学习目录 | 完整研究文档 |

## 产出沉淀（两步）

### 1. 知识库文档 + 索引登记
- 创建知识库文档（使用用户本人身份，不用 bot 身份）
- 写入多维表格索引（字段：文档名称/关键词/备注/创建日期/文档链接/文档类型/标签）
- 文档类型优先选：研究报告/调研报告/学习笔记

### 2. 本地同步
- 存 `/learnings/` 目录（按日期或领域子目录）
- 登记 CHANGELOG

## 硬性约束

- **先学后做**：用户让"试验/研究"某方向，默认先走此流程，不直接动手
- **时效**：单领域研究 ≤60 分钟
- **落地导向**：产出必须含"用户能用的动作"，不是知识堆砌
- **触发词外**：简单事实问题（如"查一下今天的天气"）→ 直接回答，不走全流程
- **不打扰**：深度研究可在睡眠时段自动执行

## 汇报格式

- 对话中：简报（结论+要点表格+来源）
- 完整版：知识库文档（事实+来源，避免空泛 AI 三段式分析）
