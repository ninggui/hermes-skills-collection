## 使用方式

每个子仓库都是独立可用的 Skill（SKILL.md + 可选 references/），放入你的 Agent 技能目录即可自动加载。

## 原则

- 每个 skill 都是真实场景沉淀，含避坑清单与验证步骤
- **零隐私**：全部内容经自动扫描，不含任何个人身份信息
- 定期更新，欢迎 PR
